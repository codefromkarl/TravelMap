# P4-1: 前端 UI（pi-web-ui 快速验证）

## 目标
用 pi-web-ui 的 ChatPanel 组件零成本启动 Web 界面，验证交互式规划体验。

## 需求
- 集成 @earendil-works/pi-web-ui 的 ChatPanel
- 配置 IndexedDB SessionStore（会话持久化）
- 注册 TravelAgent 的自定义工具
- 支持 API Key 配置（前端设置页）
- 最小化自定义代码，专注业务验证

## 验收标准
- [ ] 浏览器打开即可与 Agent 对话
- [ ] 工具调用过程可视化
- [ ] 关闭页面后重新打开可恢复历史会话
