# 天气驱动的旅行规划

## 背景与目标

TravelMap 已有天气查询、`TripPlan.weatherInfo` 和地图天气 badge，但浏览器实际运行链路存在工具名、字段名和元素形状不一致，天气没有稳定进入行程地图或恢复流程。

本任务把天气从“独立查询结果”升级为“逐日行程决策依据”：用户在地图路线面板中看到当天预报、风险等级和可执行调整建议；只有短期降水风险真正需要临场判断时，才提供 Windy 实时雷达外链。

## 已确认事实

- Web 端实际运行 `search_weather`，当前返回 `details.weather: string[]`。
- 增量事件却监听 `get_weather/getWeather` 并读取 `details.weatherInfo`。
- 现有 `addWeatherOverlay()` 会把同一城市多天 badge 堆在同一坐标，且完整行程重绘会清除它们。
- 行程聊天正文由外部 `pi-chat-panel` 渲染；项目自有的路线面板已经按天组织，适合作为确定性天气 UI。
- 用户已确认不做 Windy iframe、原生雷达图层或常驻天气按钮，雷达仅保留按需外链。

## 范围

### 必须实现

1. 将浏览器 `search_weather` 统一为结构化 `details.weatherInfo`，成功、空结果和错误分支都返回数组。
2. 查询支持行程开始日期；供应商不覆盖目标日期时明确返回不完整覆盖，不伪造目标日期天气。
3. 天气记录至少包含日期、城市、昼夜天气、最高/最低温、降雨概率、风向和风力；缺失字段可安全降级。
4. 最终 `TripPlan` 工具契约保留 `weatherInfo`，保存和恢复后仍可渲染。
5. 新增纯函数：按 `(date, city)` 匹配天气、确定性风险分类、建议生成、Windy URL 生成。
6. 每日路线面板显示紧凑天气摘要；中高风险显示原因和可执行建议。
7. 雷雨、降雨等短期风险（今天或明天；高风险降水可例外）显示本地化“查看实时雷达”外链；晴天和无坐标时不显示。
8. 国内行程坐标转换为 WGS-84 后再构造 Windy 链接；链接使用新标签页和 `noopener noreferrer`。
9. 提示词要求最终行程逐日包含天气事实和调整建议，不得捏造供应商未返回的字段。
10. 中文、英文、日文新增文案保持键集合一致，并满足键盘访问和移动端换行。
11. Agent 需要用户确认方向或策略时，每轮先提供 2-4 个互斥编号选项，推荐项置顶并说明理由，同时保留“其他”自由输入；不得默认只抛出开放问题。无法合理枚举的客观事实可直接询问。

### 明确不做

- Windy iframe、弹窗或嵌入页面。
- Windy/第三方原生雷达瓦片图层。
- 常驻地图天气按钮。
- 天气动画、时间轴或温度 SVG 图表接入。
- 重构 `pi-chat-panel` 或现有天数筛选条。
- 将模拟数据或超出预报范围的数据展示为真实目标日期预报。
- 本任务不统一重构 `src/` 后端天气 provider；范围限定为当前浏览器产品路径。

## 确定性风险规则

- `high`：雷暴/冰雹/暴雨/大雨/大雪，降雨概率 `>= 70%`，风力 `>= 6` 级，最高温 `>= 35°C` 或最低温 `<= 0°C`。
- `medium`：一般雨雪/雾，降雨概率 `>= 40%`，风力 `4–5` 级，最高温 `>= 32°C` 或最低温 `<= 5°C`。
- `low`：存在可信预报且无以上条件。
- `unknown`：无匹配预报、数据不可信或关键字段无法使用；不得默认为低风险。

建议必须说明行动变化，例如调整户外时段、优先室内备选、避开户外高暴露活动或准备防晒/保暖用品。

## 验收标准

1. `search_weather` 返回结构化数组；未知城市、无数据、HTTP 错误均返回 `weatherInfo: []` 且不抛出未处理异常。
2. 行程日期在供应商范围内时，天气日期与请求开始日期一致；范围外时明确标记 coverage 不完整。
3. 单城市、多城市、移动日均按日期和城市正确匹配，不串用其他城市天气。
4. 路线面板每个有匹配天气的日期恰好显示一行摘要，重复渲染不重复插入。
5. 高风险与中风险边界按规则稳定分类；缺失数据为 unknown。
6. 降雨风险日期显示建议；晴天不显示雷达链接。
7. 雷达 URL 使用当天景点、酒店或城市中心的有效坐标并转换为 WGS-84；无坐标不生成链接。
8. 外链包含 `target="_blank"` 和 `rel="noopener noreferrer"`，点击不会触发路线日标题导航。
9. UI 不出现 `undefined`、`null`、`NaN` 或空警告行。
10. zh/en/ja 文案键一致，375px 宽度下摘要可换行且不遮挡控件。
11. 既有地图底图切换、路线面板、天数筛选及地图/聊天联动测试保持通过。
12. 行程方向、天气调整和取舍确认均为“推荐选项优先 + 自由输入兜底”，用户可回复编号、选项文字或自定义内容；已知答案不重复询问。

## 开放问题

无。用户已批准按推荐范围实施。
