❓ 帮助中心

了解如何使用旅图 TravelMap，快速生成您的专属旅行计划

🚀 快速入门

  1. 打开旅图 — 访问 travel.codefromkarl.xyz，登录或使用免费体验。
  2. 描述需求 — 在对话框输入目的地、天数、人数、预算等信息。例如："规划一个3天杭州亲子游，带5岁小朋友"。
  3. 查看行程 — AI 自动生成每日行程，右侧地图实时展示路线和景点。
  4. 微调优化 — 继续对话微调行程，例如："第二天下午加一个博物馆"。
  5. 导出分享 — 支持导出 Markdown、PDF、图片、分享链接和二维码。

✨ 核心功能

  • AI 行程规划 — 支持多城市联游、预算控制、特殊人群适配
  • 交互式地图 — 实时渲染路线，支持标准/卫星/地形图层
  • 天气查询 — 自动查询目的地天气，提供出行建议
  • 语音功能 — 语音输入、语音播报、语音伴游问答
  • 多模型支持 — DeepSeek / OpenAI / Anthropic / Google 等
  • 多语言 — 中文、English、日本語
  • 小红书攻略 — 集成小红书笔记搜索，获取真实旅行经验

📋 常见问题

免费体验有什么限制？
未登录用户可免费体验 1 次完整行程生成 + 1 次微调。登录后可获得更多免费次数。我们仅获取您的公开头像和昵称，不收集其他个人信息。
需要配置 API Key 吗？
默认使用共享 DeepSeek 模型，无需任何配置即可使用。如果您有自己的 API Key（OpenAI、Anthropic、Google 等），可在「模型配置」中切换，获得更好的体验。
生成的行程可以编辑吗？
可以！生成行程后，继续在对话框中告诉 AI 您的修改需求，例如："把第三天的景点换成西湖"、"增加预算到 8000 元"，AI 会基于已有行程进行微调。
支持哪些目的地？
支持全球任意目的地。国内城市数据更丰富（景点、酒店、餐厅推荐更详细），海外目的地也能生成基础行程。支持多城市联游，例如 "上海 → 杭州 → 苏州 5日游"。
如何导出和分享行程？
行程生成后，点击工具栏中的导出按钮：
  • MD — 导出 Markdown 文件
  • PDF — 打印友好格式
  • 图片 — 生成 900×1200 行程卡片
  • 链接 — 生成可分享的短链接
  • 二维码 — 扫码查看行程
  • 长图 — 小红书风格攻略长图
地图上的路线颜色代表什么？
地图路线颜色表示风险等级：🟢 绿色 = 低风险、🟡 黄色 = 中风险、🔴 红色 = 高风险。蓝色实线为市内景点路线，蓝色虚线为城际路线。风险因素包括天气、交通状况等。
出行人群设置有什么用？
点击左侧面板中的「出行人群」可设置旅行者构成（成人、老人、儿童、婴幼儿等）和偏好（预算、饮食忌口、必去景点、旅行风格）。AI 会根据这些信息定制适合您的行程，例如带老人会减少高强度步行、带儿童会增加亲子景点。
语音功能怎么使用？
  • 语音输入 — 点击输入框旁的麦克风按钮，说出您的需求
  • 语音播报 — 生成行程后点击「语音播报」按钮收听行程
  • 语音伴游 — 在旅途中点击「语音伴游」可实时提问
语音功能需要浏览器授权麦克风权限，推荐使用 Chrome 或 Safari。
我的数据安全吗？
您的行程数据仅存储在浏览器本地（IndexedDB），不会上传到我们的服务器。认证信息通过安全的 OAuth 方式获取，我们仅读取您的公开头像和昵称。详见 隐私政策。
遇到问题怎么办？
  • 如果 AI 响应失败，请检查网络连接或稍后重试
  • 如果地图显示异常，尝试刷新页面
  • 如果遇到 Bug，请通过页面底部的「反馈」按钮报告
  • 也可以在 GitHub Issues 提交问题
